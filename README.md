# BG3 Mod Manager Redux

**BG3 Mod Manager Redux** is the Windows manager for bg3 mods: load order, nexus / mod.io inbox, script extender notes. Builds on LaughingLeader.

## How to use
1. Download v0.1.0-alpha.16.4.4.
2. Extract `BG3-Mod-Manager-Redux.zip`.
3. Run the manager (.NET 8).
4. Point it at BG3. Review load order. Sync.

## FAQ

**Not loading?**
Check .NET 8 and the BG3 Mods folder. Notes in `files/notes/`.

**Vortex?**
Separate manager. This zip is Redux.

**Script extender?**
Norbyte BG3SE is a different install. Redux can sit beside it.

## Requirements
Windows 10/11. .NET 8. Baldur's Gate 3.
